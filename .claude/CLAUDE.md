## Project Overview

This project targets the **Monarch Blocks** refreshable braille display for blind users.

### Display Specifications

- **Character grid:** 32 columns × 10 rows of braille characters
- **Pin grid:** 96 × 40 pins (each braille cell is 3×4 pins)

### Documentation

Display documentation is located in the `monarch-docs/` directory. Refer to it for braille cell layout, pin addressing, rendering, and hardware interface details.
